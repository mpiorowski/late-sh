## 1. Summary [STABLE]

`late-web` is the public Axum web frontend for `late.sh`.

It serves Askama-rendered pages and static assets for:

- Landing (`/`, `/status`) and the public listen page (`/listen`, `/listen/state`)
- Read-only Artboard gallery (`/gallery`) and a page per hung piece (`/gallery/pieces/{id}`)
- Public work profiles (`/profiles`)
- The Late Edition (`/paper`, dated back issues, and its RSS feed)
- Stable audio stream proxy (`/stream`)

Every page carries a preview card (Open Graph and Twitter tags) for the
link unfurl a chat or Mastodon shows when it is pasted; a profile unfurls
into its runner's poster, a gallery link into its snapshot and a piece's
page into the piece, all drawn server-side as PNG by
`pages/shared/board_png.rs`. The same renderer draws the herald's pictures
(`late-ssh/src/app/herald`): a board cropped to what is drawn, a piece,
and two text cards, the week's games and the paper's front page.

The crate depends on `late-core` for DB access, telemetry, shutdown handling, and shared models. It depends on `dartboard-core` for decoding Artboard snapshot canvases.

## 2. Entrypoints And App Shape [STABLE]

- `src/main.rs` is the binary entrypoint. It initializes `late_core` telemetry with service name `late-web`, loads `Config::load()` (profile selected by `LATE_ENV`), builds a no-proxy `reqwest::Client`, creates `late_core::db::Db::new(&config.db)`, binds `0.0.0.0:{config.port}`, and shuts down through `late_core::shutdown::wait_for_shutdown_signal()`.
- `src/lib.rs` exposes `AppState { config, db, http_client }` and `app(state) -> Router`.
- `app(state)` merges `pages::router()`, serves `/static` from `late-web/static`, adds `/test`, redirects unknown routes to `/`, wraps the router with `late_core::telemetry::http_telemetry_middleware`, then attaches state.
- `/test` intentionally returns an `AppError` for exercising error/telemetry behavior.

### Runtime Config [STABLE]

Required environment variables:

- Config is profile-based (`src/config.rs`, keyed by `LATE_ENV=dev|dev2|prod`, mirroring late-ssh). The only env reads are `LATE_ENV` and the DB credentials (`LATE_DB_USER`/`LATE_DB_PASSWORD`/`LATE_DB_NAME`). Listen port, `ssh_internal_url` (server-side URL for `late-ssh` API calls), `audio_base_url` (upstream Icecast proxied by `/stream`), and `public_base_url` (where the outside world reaches these pages, no trailing slash: the absolute links in preview cards and the paper's feed; `https://late.sh` in prod) are literals per profile.

DB config is built from the profile via `late_core::db::Db::new(&config.db)`.

Local defaults are generated by the root `Makefile`; production values live in `infra/service-web.tf`.

## 3. Routes [STABLE]

`src/pages/mod.rs` is the route composition root.

| Route | Owner | Purpose |
|---|---|---|
| `GET /` | `pages/home` | Landing page with SSH/CLI copy actions and links into gallery, profiles and the paper. |
| `GET /status` | `pages/home` | HTMX now-playing/listeners fragment for the landing footer. |
| `GET /thanks` | `pages/home` | Donation shortlink: temporary (307) redirect to `https://ko-fi.com/mateuszpiorowski`. Also supports `HEAD`. |
| `GET /listen` | `pages/listen` | Public listen page. No token, no pairing, no per-user state. Plays the Icecast mounts and guest radio stations through one `<audio>` element and the community queue through the official YouTube IFrame player. |
| `GET /listen/state` | `pages/listen` | Same-origin JSON proxy of late-ssh `/api/listen`, forwarded verbatim. Polled by the page every 10s; late-ssh reads it entirely from memory, so it costs no DB work. |
| `GET /gallery?key=...` | `pages/gallery` | Read-only Artboard snapshot gallery from DB. |
| `GET /gallery/{key}/image.png` | `pages/gallery` | The snapshot as a PNG, the gallery page's preview-card picture; 404 for a key nobody saved. `?crop=x,y,width,height` (cells) renders only that rectangle, at its own width's scale: the herald's board picture. A crop that does not parse or reaches past the board is 400. |
| `GET /gallery/pieces/{id}` | `pages/gallery` | One hung piece on a page of its own (`piece.html`): title, `~artist`, hung date, applause, the canvas drawn by `board.js` with a save-PNG link (`static/poster.js`), and a preview card pointing at its PNG. The herald's piece posts link here. 404 for an unknown id, a path that is no id, or a piece taken down. |
| `GET /gallery/pieces/{id}/image.png` | `pages/gallery` | The piece as a PNG, the piece page's card picture and the herald's; 404 as the page. |
| `GET /games/week/{YYYY-MM-DD}/image.png` | `pages/games` | The week ending on the date in every game as a text card (`week_card`): a section per shelf (`leaderboard::Shelf`: ARCADE, LOBBY, DOORS), one line per game anyone played with its best and no name, from `leaderboard::week_bests`. Drawn on request from the games' own tables, nothing stored; the herald's Sunday picture; no page. 404 for a week nobody played or a path that is not a date. |
| `GET /profiles` | `pages/profiles` | Public work profile index. |
| `GET /profiles/{slug}` | `pages/profiles` | Public work profile detail, or 404 template. |
| `GET /profiles/{slug}/poster.png` | `pages/profiles` | A standing runner's poster as a PNG, the profile's preview-card picture; 404 without a profile, a standing runner, or a poster. |
| `GET /paper` | `pages/paper` | The Late Edition: the newest edition with a printed section (today's date with nothing on it while the press has never printed). |
| `GET /paper/{YYYY-MM-DD}` | `pages/paper` | A dated edition; 404 for a day with nothing to show or a path that is not a date. |
| `GET /paper/feed.xml` | `pages/paper` | RSS 2.0 of the last 20 editions with a printed column, newest first. |
| `GET /paper/{YYYY-MM-DD}/image.png` | `pages/paper` | The edition's front page as a text card (`front_page`): the masthead, the dateline, YESTERDAY ON LATE.SH whole, and the head of OUTSIDE and WHAT WE WERE READING (`CARD_COLUMN_LINES` each). The herald's picture on a day with nothing drawn. 404 when no column printed, or for a path that is not a date. |
| `GET /terms` | `pages/legal` | Terms of service and acceptable use policy. Static Askama page; operator identity (`OPERATOR_NAME`, `CONTACT_EMAIL`) and `EFFECTIVE_DATE` are module consts, deliberately not env config, since they are document content that must not vary per deployment. Bump `EFFECTIVE_DATE` on any substantive edit. The service is 18+ throughout and permits consensual adult content in any room, deliberately with no marked-room or content-gate mechanism: moderators handle placement by hand. Because chat renders images inline and automatically, the page discloses that adult content can be encountered without being opened; keep that disclosure if the terms are edited. `admin@dwarfforge.io` is both the DSA Article 16 notice address and the GDPR controller contact. |
| `GET /stream` | `pages/stream` | Long-running `audio/mpeg` proxy to the default `chill` Icecast mount with silence fallback. |
| `GET /stream/{mount}` | `pages/stream` | Long-running `audio/mpeg` proxy to selected Icecast mounts; `classical` is accepted, unknown mounts fall back to `chill`. |
| `GET /live/{id}` | `pages/live` | Public "watch me" stream page (unlisted per-stream capability id). LiveKit subscribe-only client; video + room audio muted until a click. `/live/{id}/state`, `/live/{id}/grant`, `/live/{id}/heartbeat` are same-origin proxies of the late-ssh `/api/stream/watch/*` routes, forwarding status codes (404 = stream gone). |
| `GET /golive/{token}` | `pages/live` | Streamer broadcast console: screen picker (`getDisplayMedia`), browser mic off by default, room audio muted by default. `/golive/{token}/grant` and `/golive/{token}/state` proxy the late-ssh publish routes. Capability ids are validated (`valid_capability_id`) before touching any internal path: base64url shape (`[A-Za-z0-9_-]`, ≤64), matching what `late-ssh`'s `registry::capability_id` mints — narrowing that set would 404 live streams. |
| `GET /test` | `lib.rs` | Error simulation endpoint. |
| fallback | `lib.rs` | Temporary redirect to `/`. |

Important route details:

- late-web does not speak the pair WS. `/api/ws/pair` is for the native CLI and its webview helper only.
- `gallery` reads saved `artboard_snapshots` rows through `late_core::models::artboard::Snapshot`, and a piece through `ArtboardPiece::find` (no viewer, so no hand marked); it does not read live `late-ssh` memory. The gallery page itself does not list pieces; each has only its own page. Default selection falls back to `main`, then first daily, then first monthly, then first curated snapshot. The gallery renders live, daily, monthly, and curated snapshot lanes. The canvas pans by mouse drag or one-finger swipe, zooms by wheel or pinch (about the moving pinch midpoint, so two fingers also pan), and fits to view on double-click or double-tap (two stationary taps under 300ms and 30px apart; a flick-pan never counts as a tap). Toolbar and topbar buttons grow to 2.6rem under 768px for touch targets. The cells are drawn by `static/board.js` from the JSON `snapshot_data` builds.
- `profiles` reads `WorkProfile`, `Profile`, `Showcase`, and `DeadchannelRunner` models from DB. The index limits to 100 and sorts by the author's last login (`users.last_seen`), newest first, each row dated with it. Detail pages render profile bio through sanitized Markdown with raw HTML stripped, split comma-separated contact entries, and only create links for `http://`, `https://`, or email-like values. A standing deadchannel runner's poster (the 32 by 12 picture painted at PRINTS, `DeadchannelRunner::poster`) hangs above the hero, drawn by `static/board.js` exactly like a `/gallery` snapshot (`pages::gallery::canvas_json`, script-safe JSON), with a "save PNG" link once the fonts are in (`static/poster.js`). A runner who left, or a profile with no runner behind it, shows none; the runner's face is not drawn on the web. Every contact and link anchor carries `rel="me"`: an author who puts their Mastodon profile URL (`https://instance/@you`, not the `@you@instance` handle, which renders as plain text) in links or contact, and the late.sh profile URL in their Mastodon profile's links, gets the link shown verified there, with no field of its own. The page's preview card names the author and, for a standing runner, points at `/profiles/{slug}/poster.png`; otherwise at the site's picture.
- `paper` reads what the press in late-ssh left (`PaperEdition`, `PaperSectionRow`; the contract and the sections in `late-ssh/src/app/paper/CONTEXT.md`, "The public web") and prints the operator's `#announcements` as written (`ChatRoom::find_public_non_dm_by_slug` plus `ChatMessage::list_public_room_between_with_author` over `PaperEdition::window`, the newest `ANNOUNCEMENTS_LIMIT`), YESTERDAY ON LATE.SH, WHAT WE WERE READING and OUTSIDE. Room columns never reach the web; NEW WORK and ELSEWHERE are per reader and stay in the terminal. An announcement over an edition the press has not swept yet (`is_swept`) is held back, as it is at login. Earlier/later leaf by `PaperSectionRow::nearest_ready`. The feed merges the recent yesterday, reading and outside columns by edition, in page order; each item's description is the columns as HTML escaped once in Rust (`shared/text.rs::escape_html`) and once more by the XML template, which is the double escaping a reader unescapes.
- `stream` proxies Icecast mounts from `config.audio_base_url`; `/stream` maps to `chill`, `/stream/classical` maps to `classical`, and unknown mounts fall back to `chill`. `upstream_stream_url()` appends the selected mount once.

## 4. Templates And Static Assets [STABLE]

- `askama.toml` sets the Askama template root to `src`.
- `src/pages/app.html` is the global HTML shell. It loads `/static/style.css`, HTMX from unpkg, and Alpine from jsDelivr. Landing/social metadata frames `late.sh` as a command-line clubhouse for computer people, not developers-only. The preview card (Open Graph and Twitter tags) is the `meta` block, filled by the `card` macro in `src/pages/shared/meta.html` with the site's own card; a page with a card of its own (profiles, gallery, paper) imports the macro and overrides the block with its `og_*` and `page_url` fields. The site picture's path and alt text live once, in `src/pages/shared/meta.rs`: the shell's card reads its constants, and a page with no picture of its own falls back to `meta::site_image`. The picture itself (`static/og-image.png`, the night-city skyline) is drawn by `scripts/gen_og_image.py` through this crate's board PNG renderer, so it looks like the gallery and poster pictures; rerun the script against a running dev stack to change it. The shell has no config, so its card names `https://late.sh`; a page's own card is built from `public_base_url`. The shell also advertises the paper's feed (`rel="alternate"`).
- `src/pages/layout.html` extends `app.html` with the centered default page layout.
- Full-screen experiences such as `/gallery` extend `app.html` directly.
- HTMX partial templates live beside their page owner, currently `home/status.html`. The listen page has no HTMX partial; it polls `/listen/state` from Alpine and drives both the `<audio>` element and the YouTube player from that one response.
- Tailwind source is `static/input.css`; compiled output is committed as `static/style.css`. Rebuild with `npm run tailwind:build` after any class change, or the new classes are missing at runtime.
- Contrast floor: every real text color on the dark shell must clear 4.5:1. In practice that means `text-gray-400` or lighter (`gray-300`/`gray-200` for body copy) and `text-green-400` for accents; `text-gray-500` is reserved for decorative glyphs (`#`, `·`, `├─`). Gallery uses hand-written CSS, where `#9ca3af` is the dim-text floor.
- The landing page must keep a visible link to the source repo and an explanation of what the optional `late` companion CLI does next to the piped-install commands. Both exist because a `curl | bash` with no repo link reads as a dark pattern. It also keeps `rel="me"` links to the herald's accounts (`https://fosstodon.org/@late`, `https://bsky.app/profile/late.sh`, `late-ssh/src/app/herald/CONTEXT.md`): the Mastodon profile lists `https://late.sh`, and the link back is what shows it verified there.
- npm scripts in `late-web/package.json`:
  - `npm run tailwind:watch`
  - `npm run tailwind:build`
- Static fonts include Symbols Nerd Font and Noto Sans Symbols 2 (for legacy computing symbols) under `static/fonts/`, declared once in `static/board.css` for every page that draws Artboard cells (`static/board.js`: `/gallery`, a runner's poster on a profile, and a piece's page; the last two through `static/poster.js`).
- `src/pages/shared/card.rs` turns lines of text into a cell canvas for `board_png`: `CARD_COLUMNS` (64) wide inside a two-cell margin, each line in its `Ink` (the masthead `green-400`, a heading `green-500`, the body the board's default ink, datelines `#9ca3af`), `paragraph` word-wrapping by display width and ending a cut paragraph in an ellipsis. The arcade's week and the paper's front page are built on it, so the herald's cards look like the boards it posts.
- `src/pages/shared/board_png.rs` is the server-side twin of `board.js`: a `dartboard_core::Canvas` as an RGB PNG with the same background, default ink and 14-on-16 glyph proportion, for the preview-card routes. Its font stack is compiled in (`include_bytes!`): DejaVu Sans Mono from `assets/fonts/` (the monospace face the browser's stack names but ships no file for; its license sits beside it) and the two symbol faces from `static/fonts/`. A glyph no face carries draws nothing. Cells scale so a board comes out about 1536px wide (`cell_size`: 2px to 48px a cell), and the response carries ten minutes of public cache. Handlers call `render_blocking`, never `render`: the 250m CPU limit leaves tokio one worker, so a render runs on the blocking pool, one at a time behind a single permit, and a burst of unfurls queues instead of stalling every page and `/stream` proxy on the pod.

## 5. Integration Contracts [STABLE]

### late-ssh API And WebSockets

- Server-side now-playing fetches call `{config.ssh_internal_url}/api/now-playing` from `pages/shared/now_playing.rs`.

### Listen page

`/listen` is a follower of one global feed, with no per-user state anywhere.
The shape of `/listen/state` (forwarded verbatim from late-ssh `/api/listen`):

```json
{
  "listeners": 12,
  "audio_mode": "youtube",
  "streams":  { "chill":      { "artist": "...", "title": "..." } },
  "stations": { "chillsynth": { "label": "chillsynth", "artist": "...", "title": "...",
                                "stream_url": "https://stream.nightride.fm/chillsynth.mp3",
                                "provider": "nightride", "provider_url": "https://nightride.fm" } },
  "youtube":  { "current": { "video_id": "...", "title": "...", "channel": "...",
                             "duration_ms": 0, "started_at_ms": 0, "is_stream": false,
                             "submitter": "..." },
                "queue": [] }
}
```

Icecast mounts carry no `stream_url`: they are served by late-web's own
`/stream/{mount}` proxy, so the page builds that URL itself. Guest stations
do carry one, because clients fetch that audio directly from the provider. The
page groups them into one section per `provider`, each with a link to
`provider_url`.

Attribution is a requirement here, not decoration. The Nightride agreement asks
for visible artist credit, and the house tracks are CC-BY. The page shows
`artist - title` for both, a `streamed directly from` link per guest provider, a
link to `MUSIC.md`, and
`queued by <user>` for YouTube.

- **Source order is a product rule.** Guest stations first (one section per
  provider), then the community queue, then house radio last. Our own playlist
  is the fallback option, not the headline. `listen_test.rs` asserts the ordering.
- **Joining mid-track.** The page seeks in using `started_at_ms` rather than
  restarting the current song. That is the same one-shot-seek idea the webview
  helper uses, and it does not reintroduce drift correction: after the initial
  seek each listener plays its own timeline.

### Stream Proxy

`/stream` and `/stream/{mount}` must:

- Return `200 OK`.
- Set `Content-Type: audio/mpeg`.
- Set no-store/no-cache headers.
- Keep yielding audio bytes indefinitely.
- Yield non-empty bundled silence chunks from `assets/silence.mp3` when upstream is down, errors, or ends.
- Retry the upstream every 500ms after a silence chunk.

This endpoint is used by the `/listen` page and by local CLI workflows.

### Database-Backed Pages

- `/gallery` decodes `Snapshot.canvas` as `dartboard_core::Canvas` and `Snapshot.provenance` as `cells: Vec<(Pos, String)>`.
- `/profiles` uses public work-profile slugs and user/profile/showcase data, plus the runner's poster canvas; a poster that fails to decode is logged and the page shows none (and its PNG route is 404).
- `/paper` reads `paper_sections` and `paper_room_editions` through the paper model, and the announcements room's messages through the chat models; it writes nothing.
- `/games/week/...` reads the daily-win tables, `game_score_events`, `daily_matches` and `door_runs` through `leaderboard::week_bests`; it writes nothing.
- These pages require the DB pool in `AppState`; route tests that exercise them should use DB-backed integration infrastructure.

## 6. Error, Telemetry, Metrics [STABLE]

- `src/error.rs` maps `AppError::Internal` and `AppError::Render` to HTTP 500.
- The error page uses `pages/error.html`; if rendering the error page fails, the response falls back to plain text.
- Current error responses include internal error text in the rendered body. Be careful before attaching secrets or sensitive upstream context to errors.
- Router-level HTTP telemetry comes from `late_core::telemetry::http_telemetry_middleware`.
- Outbound now-playing requests use `send_traced()` so trace headers propagate to `late-ssh`.
- `metrics.rs` is no-op unless built with the `otel` feature.
- Current web metrics:
  - `late_web_page_views_total{page,has_token}`
  - `late_web_now_playing_fetch_total{result}`
- Preserve non-`otel` compilation when adding metrics.

## 8. High-Risk Invariants [STABLE]

- Nothing in the browser talks to `late-ssh` directly. Everything goes through late-web over `config.ssh_internal_url`, which is why late-ssh carries no CORS layer.
- A failed `/listen/state` poll must leave the last rendered state in place rather than blanking the page; the stream keeps playing regardless.
- `listen/page.html` keeps exactly one audible surface: picking any source stops the others. The YouTube IFrame API is only fetched once someone actually picks YouTube, and a listener joining mid-track seeks in via `started_at_ms` instead of restarting the song.
- Gallery JSON is embedded into a page script context. Keep the explicit `</` to `<\/` replacement or use an equivalent safe embedding strategy.
- Gallery rendering depends on `dartboard-core` canvas/provenance schema. Coordinate with `late-ssh/src/app/artboard/CONTEXT.md` and `late-core` migrations before changing it.
- Profile status strings are presentation-coupled to `open`, `casual`, and `not-looking` for labels and CSS state.
- The paper on the web prints the sections and the announcements only. A room's column is a conversation summary and stays inside the clubhouse; adding one to `/paper` is a product decision, not a template change.
- `rel="me"` on profile contact and link anchors is what Mastodon's link verification looks for. Dropping it silently un-verifies every member who set it up; the same on the landing page's account links un-verifies the herald.
- The `/stream` fallback must never yield empty chunks; some clients treat empty reads as stream end.
- `metrics.rs` must compile both with and without the optional `otel` feature.

## 9. Local Development [VOLATILE]

Full Docker dev stack:

```bash
make start
```

Native Rust services with Docker infrastructure:

```bash
docker compose up -d postgres icecast liquidsoap
cargo run -p late-ssh
cargo run -p late-web
```

Tailwind rebuild:

```bash
cd late-web
npm run tailwind:build
```

Do not assume `cargo run -p late-web` has enough env by itself. It needs `LATE_ENV` and the DB credential vars from `.env` or the shell.
