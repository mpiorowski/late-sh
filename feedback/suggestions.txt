# text editor (for chat input)
- only work for cli (if it can open user prefer text editor like vim)

## why?
editing ur text in late can be a bit "annoying" since late doesn't fully support it, everything u can do is pretty barebone and a bit clunky.

so I think wouldn't it be cool if u could use ur fav text editor to do that one, especially when u're editing a big paragraph of text.

## how it work:
- shortcut: `ctrl e`
- requirement: is using chat input. && have a text editor configured in the settings

> settings: tweaks tab -> compose section
- **Use external text editor**: <string> (default: none)
EX:
- **Use external text editor**: nvim

late will use the same string that use to trigger that text editor. After user done editing they can *save*, it will close the text editor and apply the result to the chat input.

this option act as an alternative way to edit ur text, I know (especially nvim user) have a lot of plugins that allow them edit paragraph much faster, so this suggestion might be it.
